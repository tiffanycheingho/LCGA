# LCGA

curated data sheets used for Liu et al. "Functional and Structural Brain Connectivity of Default Mode, Central Executive, and Attentional Regions Predict Longitudinal Trajectories of Depression and Anxiety Symptoms in Adolescents with Major Depressive Disorder" (published in BMC Psychiatry, 2026)

Scripts that were applied to generate the preprocessed neuroimaging data can be found under "TIGER"
